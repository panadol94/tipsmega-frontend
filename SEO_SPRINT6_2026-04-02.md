## Outcome
- Homepage improved meaningfully after reducing client JS and moving static sections to server render.
- `/trusted` only improved marginally and remains the main optimization target.

## Recommendation for next sprint
Focus specifically on `/trusted` architecture:
1. Split `TrustedClient` into smaller islands
2. Move static SEO/marketing blocks to server render
3. Reduce per-card client logic and animated decoration further
4. Consider server-side data fetch + smaller interactive wrappers only where needed
