## Daily Pack Helper
Generate the daily execution pack from the 30-day calendar:

```bash
npm run seo:daily-pack
```

Optional overrides:

```bash
npm run seo:daily-pack -- --date=2026-03-15
npm run seo:daily-pack -- --tz=Asia/Kuala_Lumpur
SEO_DATE=2026-03-15 SEO_TIMEZONE=Asia/Kuala_Lumpur npm run seo:daily-pack
```

Notes:
- Default timezone is `Asia/Kuala_Lumpur` to avoid UTC rollover issues after midnight.
- Output file format: `out/seo-daily-pack-YYYY-MM-DD.json`
- If exact date is missing, the helper picks the next planned calendar item.
